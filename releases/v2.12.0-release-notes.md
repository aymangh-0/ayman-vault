# Ayman Vault v2.12.0 — Early Public Preview

This is the first public build of Ayman Vault, a local-first personal workspace and evolving
second brain for Windows. Your vault stays on your machine.

**This is an early preview.** It is under active development, the interface is still changing, and
you should keep backups of anything important.

## What's in this release

### Search that actually finds things
- Local full-text search across projects, areas, notes, prompts, and resources
- Results ranked by **relevance** rather than by date, so the best match comes first
- **Highlighted snippets** showing where the match is, drawn from your original text
- **Arabic-aware matching** — searching `احمد` finds `أحمد`; diacritics, tatweel, alef maqsura,
  ta marbuta and Arabic-Indic digits no longer break results
- Mixed Arabic and English in a single query
- Prefix matching as you type, and a manual *Rebuild search index* action in Settings

### A structure for your material
- **Inbox** for anything you have not filed yet, with one-click filing into a project or an area
- **Areas** for ongoing topics and domains
- **Archive** — move projects, areas, notes, prompts, or resources out of your active workspace
  without deleting them; archived items keep everything and can be restored at any time
- **Daily** and **quick capture** note types alongside ordinary notes
- Navigation reorganized around this structure

### Capture in seconds
- **Ctrl+K** opens a command palette from anywhere in the app
- Search your whole vault and jump straight to any result
- **Quick Capture** — write a thought and save it to your Inbox without leaving the page you were
  on. Typing alone never creates anything; capture is always deliberate.

### Interface
- Refreshed typography, spacing, cards, focus states, and loading and empty states throughout
- **Dark and light themes**
- **English and Arabic**, with a fully mirrored right-to-left layout

### Also included
- **Reminders** with overdue and upcoming views and an in-app due banner. These are in-app only —
  nothing runs while the application is closed.
- **Backup and restore** — copy your database somewhere safe and restore from any previous backup
- Markdown and TXT import and export for notes, Markdown for prompts

### AI — optional, and off by default
AI does nothing until you turn it on and ask for something. Nothing runs in the background, at
startup, or when a page loads.

- **Local AI** through [LM Studio](https://lmstudio.ai/) on your own machine — summarize a note,
  clean up a prompt, ask a custom question about a single note or prompt, generate a project
  summary or a development prompt. This traffic does not leave your computer.
- **Cloud AI** is optional and separate. A small number of project-level tasks can use a provider
  you configure yourself with your own API key. Before anything is sent you are shown the exact
  content, sanitized, and you have to confirm it. Only the single item you selected is sent —
  never your whole vault — and a failed local task is never silently retried against the cloud.

## Privacy

- Your vault is a local SQLite database. No account, no sync, no telemetry, no analytics, no
  crash reporting, no update check, no background upload.
- Local file paths are kept out of the interface and out of search results.
- If you never configure a cloud AI provider, no content leaves your machine.

## Known limitations

- **Windows only.** There are no macOS or Linux builds.
- **The installers are unsigned.** Windows may warn that the publisher is unknown. This is expected
  for unsigned software from an individual developer.
- **Arabic word prefixes are not stripped.** Search matches whole words, so a word written with an
  attached prefix — `وقاعدة` rather than `قاعدة` — is found by the form you actually typed.
- **"Archived" means two things for projects.** A project can have an *Archived* status (a
  lifecycle state; the project stays in your active list), and separately it can be moved to the
  *Archive* (which hides it). The wording is confusing and will be revisited.
- **Ctrl+K does not open while you are typing in a text field**, deliberately, so it can never
  swallow a keystroke meant for the text you are editing.
- **No automatic updater.** New versions are announced here and installed the same way.
- **No confirmation message after a quick capture** — the palette simply closes; your note is in
  the Inbox.

## Install

Download either installer below and run it.

| File | Size |
|---|---|
| `Ayman.Vault_2.12.0_x64-setup.exe` (NSIS) | ~2.8 MB |
| `Ayman.Vault_2.12.0_x64_en-US.msi` (MSI) | ~3.7 MB |

64-bit Windows. Uses the Microsoft Edge WebView2 runtime, already present on current Windows 11.

### Upgrading from an earlier build

Installing this version over an existing Ayman Vault upgrades it in place. Your vault is stored
separately from the application and is not touched by the installer, so your data carries over.
As always with an early preview, take a backup first — *Backup now* in Settings.

### Verifying your download

SHA-256 checksums — integrity only, these are not signatures:

```
c433c256b11a26a37cec5f04819de66225fbb142ac89be27467a309b5b2a78a8  Ayman.Vault_2.12.0_x64_en-US.msi
99506cbe8cd8c2a6dcd0b29514198eff8743563a5c13f9718fe893edbcf1f94d  Ayman.Vault_2.12.0_x64-setup.exe
```

Check one in PowerShell with:

```powershell
Get-FileHash "Ayman.Vault_2.12.0_x64-setup.exe" -Algorithm SHA256
```
